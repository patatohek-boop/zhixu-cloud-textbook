## 安装和迁移

1. 保留原版，在原版“应用菜单 → 导出学习备份”保存 JSON
2. 下载本页 APK，核对 SHA-256 后按 Android 系统提示允许本次安装；不要关闭系统安全保护或卸载原版
3. 打开名称为“知序·独立版”的新App，在“应用菜单 → 导入备份（合并记录）”选择刚才的 JSON
4. 核对完成状态、收藏、笔记和答题记录。已有不同笔记会合并；主题、字号与最后阅读位置不随导入替换
5. 核对无误后仍建议保留 JSON。两个 App 各自保存记录，后续需要同步时再手动导出、导入

卸载或清除任一App的数据都会删除它的本地记录。不要在核对迁移前卸载旧版。JSON 备份未加密，请勿公开上传。未来独立版更新应使用同一包名和同一独立版证书覆盖安装；旧版证书不可用于此包。
