## 文字也是有结构的数据
字符串是 Unicode 字符序列，用单引号或双引号包围，二者都可以；需要在文字里嵌入引号时可选择另一种引号或转义。字符串不可变，`text.upper()` 返回新字符串，并不会原地修改 text。处理用户输入时，这种性质可以帮助我们保留原始记录与清理结果。

索引从零开始，`s[0]` 取第一个字符，`s[-1]` 取最后一个字符。切片 `s[start:stop:step]` 包含起点，不包含终点。把它想成在字符之间的边界剪一段，会比“数第几个字”更清楚。越界单个索引会报错，切片通常会截到有效范围；空字符串不能取首字符，应先检查长度或真假。

```python
raw = "  sensor-A, 23.50, C  "
name, value_text, unit = [part.strip() for part in raw.split(",")]
value = float(value_text)
clean = f"{name}: {value:.1f} °{unit}"
print(clean)                    # sensor-A: 23.5 °C
text = "温度"
encoded = text.encode("utf-8")
print(encoded.decode("utf-8") == text)  # True
```

先用逗号分出字段，再移除每个字段两侧空白，然后只把数值字段转换成浮点数。`strip` 不会删除文字中间的空格。这里的逗号分割适合结构简单且没有带引号逗号的输入；真实 CSV 应交给 csv 模块，否则“含逗号的名称”会被错误拆开。

## 格式化是输出约定
f 字符串中的 `{value:.1f}` 表示用一位小数的定点格式显示。展示格式和实际保存精度是两件事，value 本身仍是浮点数。对齐、宽度和科学计数法可以提高表格可读性，例如 `{x:10.3e}`。不要为了美观过早把所有数都转换成字符串，否则之后的排序可能变成字典顺序：文字“10”会排在文字“2”前面。

## 字符不是字节
Unicode 为字符提供统一表示，UTF-8 是把文字转换成字节的编码方案。一个中文字符常占多个 UTF-8 字节，因此字符串长度与文件字节数通常不同。文件读写时明确 `encoding="utf-8"`，不要依靠不同电脑的默认编码。某些视觉上的单个字符可能由多个 Unicode 码点构成，本课的简单索引并非完整的自然语言分词工具。

另外，拼接路径应使用 pathlib，构造结构化数据应使用 json；不要把字符串拼接当成所有格式处理的通用办法。对外部输入，不使用 `eval` 将文字直接当代码执行。能解析为数值或固定字段，就使用对应解析函数，让数据始终保持数据的身份。

## 文本清理应当可逆检查
保留原始字段，再生成清理后的字段，比直接覆盖更便于定位问题。比如姓名内部的空格可能有意义，编号开头的零可能是标识的一部分，不能为了“看起来像数字”就转换成整数。清理规则应由字段含义决定。
字符串比较默认区分大小写，空白和不同 Unicode 表示也可能影响相等。对于用户账号或关键词，可以按明确规则规范化；对于实验编号、公式和密码，不应随意改变大小写或字符形式。
切片还能用于检查协议前缀、文件后缀或固定宽度字段，但结构复杂后应选择解析器。练习时尝试空字符串、只有空格、中文、含引号和换行的输入，逐个说明预期结果。边界样例能帮助发现“只对漂亮输入有效”的程序。
