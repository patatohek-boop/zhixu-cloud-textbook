## Unicode 字符串与字节编码
`str` 是 Unicode 码点序列，**码点**是字符编码空间中的整数编号；`bytes` 是取值 0 到 255 的字节序列。

### 编码与解码

**编码**按约定把文本转为字节，**解码**按约定把字节还原为文本。

### 码点数与可见字形数

一个屏幕上看见的字形可能由多个码点组成，因此 `len(str)` 不保证等于人眼数到的字数。

字符串不可变，字符串方法返回结果不表示原对象被修改。例如 `s.strip()` 得到去除首尾空白后的字符串；要让名字 s 改为引用这一结果，应写 `s = s.strip()`。

## 索引与切片的边界
长度为 n 的字符串，非负合法单个索引为 0 到 n−1。`s[a:b]` 在步长为正时取满足 $a\le i<b$ 的有效索引；省略端点和负索引由切片规则转换。于是 `"Python"[1:4]` 只访问 1、2、3，结果为 `"yth"`，不是四个字符。反向步长时规则不同，不能只套上述不等式。

## 例：字符串边界检查
```python
text = "温度"
data = text.encode("utf-8")
assert len(text) == 2 and len(data) == 6
assert data.decode("utf-8") == text
s = "  A  "
clean = s.strip()
assert s == "  A  " and clean == "A"
```
往返相等的前提是文本能被所选编码表示、字节未改变，且解码使用匹配编码；这不保证任意截断字节都可解码。UTF-8 多字节字符若截到中间，严格解码会失败。遇到乱码应先核对编码，不能靠删除错误字符掩盖数据丢失。

## 字符串操作与字段解析
字符串是 Unicode 字符序列，用单引号或双引号包围，二者都可以；需要在文字里嵌入引号时可选择另一种引号或转义。字符串不可变，`text.upper()` 返回新字符串，并不会原地修改 text。处理用户输入时，这种性质可以帮助我们保留原始记录与清理结果。

索引从零开始，`s[0]` 取第一个字符，`s[-1]` 取最后一个字符。切片 `s[start:stop:step]` 包含起点，不包含终点。把它想成在字符之间的边界剪一段，会比“数第几个字”更清楚。

### 单个索引与切片的越界行为

越界单个索引会报错，切片通常会截到有效范围；空字符串不能取首字符，应先检查长度或真假。

```python
raw = "  sensor-A, 23.50, C  "
fields = raw.split(",")
name = fields[0].strip()
value_text = fields[1].strip()
unit = fields[2].strip()
value = float(value_text)
clean = f"{name}: {value:.1f} °{unit}"
print(clean)                    # sensor-A: 23.5 °C
text = "温度"
encoded = text.encode("utf-8")
print(encoded.decode("utf-8") == text)  # True
```

### 按四步追踪文本转换

1. `split(",")` 按逗号分隔，返回按位置排列的字符串列表；本例明确约定恰有三个字段，位置为 0、1、2。
2. 对每个字段调用 `strip()`，得到去掉两端空白的新字符串。原始 `raw` 不被修改。
3. `float(value_text)` 才把数值文字转换为浮点数；名称和单位继续保留文本类型。
4. f 字符串负责显示，把已经算好的数按指定小数位写入输出。

此处是固定三字段的教学输入。字段数不对或数值文字不合法时，需要后面[条件](#/course/python/python-05)与[异常](#/course/python/python-14)的处理；含引号、逗号或换行的真实 CSV 应用[CSV 解析器](#/course/python/python-13)。学完[推导式](#/course/python/python-10)后，再尝试把重复清理写成简洁形式。

`strip` 只处理字符串两端，不删除中间的空格。因此名称 `"sensor A"` 会保留内部空格，只有外部空白被去掉；这一规则与“删除所有空格”不同。

## 格式化是输出约定
f 字符串中的 `{value:.1f}` 表示用一位小数的定点格式显示。展示格式和实际保存精度是两件事，value 本身仍是浮点数。对齐、宽度和科学计数法可以提高表格可读性，例如 `{x:10.3e}`。

### 显示结果和计算数据分开

不要为了美观过早把所有数都转换成字符串，否则之后的排序可能变成字典顺序：文字“10”会排在文字“2”前面。

## 编码转换
Unicode 为字符提供统一表示，UTF-8 是把文字转换成字节的编码方案。一个中文字符常占多个 UTF-8 字节，因此字符串长度与文件字节数通常不同。文件读写时明确 `encoding="utf-8"`，不要依靠不同电脑的默认编码。某些视觉上的单个字符可能由多个 Unicode 码点构成，本课的简单索引并非完整的自然语言分词工具。

另外，拼接路径应使用 pathlib，构造结构化数据应使用 json；不要把字符串拼接当成所有格式处理的通用办法。对外部输入，不使用 `eval` 将文字直接当代码执行。能解析为数值或固定字段，就使用对应解析函数，让数据始终保持数据的身份。

## 原始文本与清理规则
保留原始字段，再生成清理后的字段，比直接覆盖更便于定位问题。比如姓名内部的空格可能有意义，编号开头的零可能是标识的一部分，不能为了“看起来像数字”就转换成整数。清理规则应由字段含义决定。
字符串比较默认区分大小写，空白和不同 Unicode 表示也可能影响相等。对于用户账号或关键词，可以按明确规则规范化；对于实验编号、公式和密码，不应随意改变大小写或字符形式。
切片还能用于检查协议前缀、文件后缀或固定宽度字段，但结构复杂后应选择解析器。练习时尝试空字符串、只有空格、中文、含引号和换行的输入，逐个说明预期结果。边界样例能帮助发现“只对漂亮输入有效”的程序。
