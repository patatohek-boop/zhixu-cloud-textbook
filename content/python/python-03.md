## 先给误差一个可计算的定义
设真实值为 `x`、计算近似值为 $\hat x$。**绝对误差**为 $|\hat x-x|$；当 $x\ne0$ 时，**相对误差**为 $|\hat x-x|/|x|$。绝对误差带原量的单位，相对误差无量纲。这里的“真实值”也可换成明确给定的高精度参考值；测量误差与计算舍入是不同来源。

`int` 表示整数；`float` 在常见 Python 实现中使用有限精度二进制浮点数，不能精确表示全部实数。

### 有限表示的证明

**证明 0.1 为什么不能写成有限二进制小数：** 有限二进制小数总能写成 $m/2^k$，其中 m 为整数、k 为非负整数。若 $1/10=m/2^k$，则 $2^k=10m$；约分后的分母仍含因子 5，不可能是 2 的幂，矛盾。因此只能舍入。

## 通俗解释与容差的依据
尺子刻度有限，不意味着长度运算失效。比较两个有限浮点数 a、b 时，`math.isclose` 使用
$$|a-b|\le\max(\mathrm{rel\_tol}\max(|a|,|b|),\mathrm{abs\_tol}).$$
两个容差分别为相对与绝对允许差。比较到零时，若绝对容差为零、相对容差小于一，任何非零有限 a 都不能被认作接近零。必须根据物理量尺度选择绝对容差，不能机械复制 `1e-9`。

**误差传播推导：** 圆面积 $A=\pi r^2$，半径变成 $r+\Delta r$ 时，
$$\frac{\Delta A}{A}=2\frac{\Delta r}{r}+\left(\frac{\Delta r}{r}\right)^2.$$
仅当 $|\Delta r/r|$ 很小时才可忽略平方项，得到“面积相对误差约为半径的两倍”。这是近似式的条件，不是所有误差大小下都成立的等式。

## 数学表达式如何进入程序
Python 用 `+`、`-`、`*`、`/` 表示四则运算，`**` 表示乘方。`/` 做真除法，`//` 向负无穷取整，`%` 给出相应余数。例如 `-7 // 3` 是 -3，且恒等式 `a == (a//b)*b + a%b` 对非零整数 b 成立。括号既能改变优先级，也能向读者说明分组；对于关键公式，宁可写清楚，不要考验读者的记忆。

## 浮点数为何不是精确小数
十进制的三分之一不能写成有限小数，类似地，十进制的 0.1 在二进制中也通常需要无限位。计算机只能保存有限位，所以 `0.1 + 0.2` 的结果可能显示为 `0.30000000000000004`。这不是加法失效，而是输入和运算都发生了舍入。使用 `round` 改变显示或得到舍入值，不会让后续所有计算变成精确实数运算。

```python
import math
from decimal import Decimal
print(0.1 + 0.2 == 0.3)              # False
print(math.isclose(0.1 + 0.2, 0.3))  # True
print(Decimal("0.1") + Decimal("0.2"))
radius_m = 0.05
area_m2 = math.pi * radius_m ** 2
print(f"面积约为 {area_m2:.6f} 平方米")
```

比较近似值应采用绝对容差与相对容差。`math.isclose(a,b)` 的核心规则是差值不超过相对尺度容差与绝对容差中的较大者。接近零时必须根据问题尺度设置 `abs_tol`；否则仅靠相对误差可能无法判断“小到可以忽略”。

### 按数值规则选择类型

金额需要十进制规则时可使用从字符串构造的 `Decimal`，分数可用 `Fraction`；它们也有成本和适用边界。

## 逐步例题：圆管截面
半径为 5 厘米的圆管，先换成 0.05 米，再计算 $A=\pi r^2$，得到约 $0.007854\ \mathrm{m^2}$。

### 单位换算为什么要平方

若直接把 5 代入并把结果标成平方米，会错一万倍，因为面积的单位转换要平方。变量名写入单位可以显著减少这类错误。程序默认不会检查米和厘米能否相加，量纲责任仍属于建模者。

进行连续相减或求和时也要留意误差放大。两个很接近的大数相减可能损失有效数字；大量小数求和可考虑 `math.fsum`。输出很多位不意味着测量有那么高的精度。输入半径只有两位有效数字，就不应把计算结果的十几位小数当成实验事实。

## 用误差预算决定容差
假设长度测量只精确到十分之一毫米，面积计算显示十几位小数也不会增加物理信息。先估计输入的不确定性，再确定输出保留位数和验证容差。对于圆面积，小的半径相对误差会近似放大为两倍的面积相对误差；这来自对面积公式求导，而不是浮点计算本身。
比较两个算法时，可同时报告绝对差与相对差。例如参考值约为一百万，差一可能很小；参考值约为百万分之一，差一却非常大。接近零时，相对差会不稳定，所以需要独立的绝对尺度。
还要留意异常数值的传播：无穷大与非数值可能让后续平均、比较或绘图失真。输入阶段使用有限性检查，结果阶段检查量纲和合理范围。程序没有抛异常，只说明运算被执行，并不保证数值结论符合问题。

容差是科学判断的一部分，必须保留依据。
