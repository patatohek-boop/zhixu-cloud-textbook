## 运行准备

本节需要 NumPy 与 Matplotlib。请先完成[科学计算环境与导入核验](#/course/python/python-11)，用同一个虚拟环境解释器运行完整代码。示例数据直接在代码中建立，无需另找数据文件。本机有图形界面时 `plt.show()` 会打开图窗；无图形界面的环境可在它之前加入 `fig.savefig("cooling.png", dpi=160)`，再打开输出图片。

## 每一种图形先对应一种数学对象
散点图表示一组坐标对 $(x_i,y_i)$；折线把有顺序的点用线段连接；直方图按区间汇总频数或密度。

### 直方图面积的含义

**密度直方图**要求柱面积总和为一，不要求柱高总和为一，区间宽度变化时尤其要区分。

### 绘图对象与坐标标签

Figure 是整张图，Axes 是一个坐标区域，坐标轴标签必须同时说明变量和单位。

误差条若为标准差，表示观测离散程度；若为标准误，表示估计量的抽样波动；若为置信区间，须说明构造前提和覆盖解释。通俗地说，图不是“数值漂亮地摆上去”，每种位置、长度和阴影都在作一个可核查的声明。

## 先证明模型形状，再检查画出来是否一致
下文使用 $T(t)=20+60e^{-t/3}$，t 的单位为秒，T 为摄氏度，时间常数 3 秒。对 $t\ge0$：
$$T(0)=80,\quad \lim_{t\to\infty}T(t)=20,$$
$$T'(t)=-20e^{-t/3}<0,\qquad T''(t)=\frac{20}{3}e^{-t/3}>0.$$
所以曲线应从 80 开始、向 20 下降、下降速度逐渐减小。导数与极限给出独立于绘图库的检查依据。若图不符合这些性质，应先核对时间单位、点的顺序和公式。

这只证明**所画数学模型**的性质，不证明某台真实设备服从它。实验点应使用不同标记，残差定义为同一时刻观测减预测，不可把模型输出冒充观测。

### 对数轴的输入条件

普通实数对数轴要求对应数据为正，不能通过偷偷丢弃非正值掩盖问题。

## 图首先服务一个问题
折线图适合展示连续自变量上的变化，散点图适合比较两个变量，柱状图适合有限类别比较，直方图展示数值分布。连线意味着顺序与连续变化的解释，不应随意连接没有顺序的类别。图越漂亮并不代表证据越强，清楚的坐标、单位和数据来源比装饰更重要。

```python
import numpy as np
import matplotlib.pyplot as plt

time_s = np.linspace(0, 10, 101)
temperature_c = 20 + 60 * np.exp(-time_s / 3)
fig, ax = plt.subplots(figsize=(7, 4), constrained_layout=True)
ax.plot(time_s, temperature_c, label="Ideal cooling model")
ax.set_xlabel("Time (s)")
ax.set_ylabel("Temperature (deg C)")
ax.set_title("Cooling toward ambient temperature")
ax.grid(alpha=0.25)
ax.legend()
plt.show()
```

代码使用英文标签，避免部分电脑没有中文字体时出现缺字。曲线来自理想模型，不是实验数据；标题与说明应明确这一点。t=0 时温度为 80，时间增大后趋近环境温度 20；可以先用这些端点和极限验证图是否符合公式，再讨论美观。

## Figure 与 Axes
Figure 是整张画布，Axes 是一个包含坐标系统的绘图区。使用 fig, ax 的对象接口更容易管理多个子图，也减少全局状态造成的混乱。

### 显示与保存

plt.show 显示图；fig.savefig 可保存 PNG、SVG 或 PDF，保存路径应明确。科学出版常需要矢量格式或足够分辨率，网页展示则需兼顾文件大小和手机可读性。

坐标范围可以改变视觉印象。柱状图通常应从零起点展示长度意义；折线图是否从零开始取决于问题，但截断应明显。对数轴表达倍数变化，不能包含零或负值，读者也需要被告知其尺度。比较多个子图时，是否共享坐标范围会影响公平比较。

## 表达误差和样本
若有重复实验，可展示原始散点并叠加均值与误差条；必须说明误差条是标准差、标准误还是置信区间。它们回答不同问题，不能都称为“误差”。样本很少时平滑曲线可能制造过度确定的印象，保留原始点往往更诚实。

颜色应辅助而非独自承载关键信息，可同时使用线型、标记与直接标签。减少不必要网格、立体效果和大量图例。手机端图形要保证字体、触控和横轴标签可读；过密的数据可以提供局部查看，但不能隐藏重要异常。

## 用图形检查模型
本例冷却曲线的导数始终为负，并且下降越来越慢，因此曲线应单调下降且逐渐变平。若图上出现升温或振荡，先检查公式、时间排序和单位，而不是立即调整坐标隐藏异常。
可以增加几个人工观测点，并用不同标记表示它们，让模型曲线与观测清楚区分。若计算残差，应将观测减去相同时间点的模型预测，再画残差随时间变化，寻找系统偏离。
保存图时同时保存生成数据和代码，避免只留下无法追溯的截图。图注应说明模型假设、样本量与误差含义。用于手机阅读时，宁可拆成两个清晰图，也不要把过多小字、曲线和图例挤在一张图里。
