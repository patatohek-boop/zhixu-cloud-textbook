## 计算得到的是近似
很多方程没有方便的解析解，计算机通过有限步骤近似求解。要同时说明数学问题、算法前提、停止标准和误差来源。模型误差来自方程与现实的差别，截断误差来自有限近似，舍入误差来自有限精度表示。增加计算量通常不能消除错误模型带来的偏差。

```python
def bisect_root(f, left, right, tol=1e-10, max_iter=100):
    fl, fr = f(left), f(right)
    if fl == 0:
        return left
    if fr == 0:
        return right
    if fl * fr > 0:
        raise ValueError("端点函数值必须异号")
    for _ in range(max_iter):
        mid = (left + right) / 2
        fm = f(mid)
        if fm == 0 or (right - left) / 2 <= tol:
            return mid
        if fl * fm < 0:
            right = mid
        else:
            left, fl = mid, fm
    raise RuntimeError("未达到容差")

print(bisect_root(lambda x: x*x - 2, 1, 2))
```

对连续函数，端点异号保证区间内至少有一个根。每次保留异号半区间，因此根始终被夹住；n 次后区间长度缩为原来的 $2^{-n}$，中点误差不超过区间半长。端点同号不等于没有根，只表示这个保证无法使用。函数不连续时异号也不保证存在零点，例如跨越竖直渐近线。

## 从积分到时间推进
梯形法用小梯形近似曲线下方面积。对于足够光滑函数，在固定有限区间使用均匀步长时，复合梯形法总体误差通常为 $O(h^2)$。将步长减半并比较结果，可以观察数值是否趋于稳定，但这不是对所有奇异函数都有效的证明。

常微分方程 $y'=f(t,y)$ 的显式欧拉法为 $y_{n+1}=y_n+h f(t_n,y_n)$。它把当前斜率当作一小步内的斜率。对衰减方程 $y'=-ky$，更新系数为 $1-kh$，步长过大可能产生振荡甚至增长，即使真实解只会衰减。稳定性与精度是相关但不同的要求。

## 验证比增加小数更重要
先使用已知解析解的问题测试算法，再处理未知问题；检查单位、守恒量、端点和极限；比较多个步长，并设置最大迭代次数。SciPy 提供成熟求根、积分、优化与微分方程求解器，但调用库仍需提供正确问题和容差。本课给出核心直觉，刚性问题与误差控制属于进一步数值分析课程。

## 误差、残差与条件数
方程残差很小不一定意味着解误差很小。如果问题对输入扰动非常敏感，微小残差仍可能对应明显参数误差，这与问题的条件有关。求解前后既检查残差，也考虑函数斜率或线性系统条件。
对于数值导数，前向差分用邻近两个函数值相减再除以步长。步长变小可减少截断误差，却会放大相减舍入误差，因此误差通常不会无限单调下降。中心差分在足够光滑时有更高阶截断精度，但也需要额外函数计算。
梯形积分可先用常数与一次函数测试，因为它对这些简单情形应给出精确结果，浮点舍入除外。再用已知积分的二次函数检查步长减半后误差变化。对微分方程则可比较解析衰减解与数值轨迹，观察精度和稳定性分别怎样随步长改变。
实际科学计算最好同时保存算法、容差、步长和停止原因。如果达到最大迭代仍未满足条件，必须把未收敛状态报告出来，不能把最后一个数直接包装成可靠答案。
