## 先问标准库有没有
标准库随 Python 提供，覆盖路径、文件格式、数学、统计、日期、日志、命令行等常见任务。复用标准库可以减少自己实现细节的错误，但仍要阅读函数契约。工具箱不是算法理解的替代品：知道 Counter 在统计频数，才能发现输入粒度是否错误。

```python
from collections import Counter, deque
from statistics import mean, stdev
import random

labels = ["A", "B", "A", "C", "A"]
print(Counter(labels))  # Counter({'A': 3, 'B': 1, 'C': 1})
window = deque(maxlen=3)
for value in [1, 2, 3, 4]:
    window.append(value)
print(list(window))  # [2, 3, 4]

rng = random.Random(42)
samples = [rng.random() for _ in range(5)]
print(round(mean(samples), 4))
print(round(stdev(samples), 4))
```

Counter 表达“类别到次数”，deque 适合双端操作；maxlen 限制窗口长度，追加新值时会自动丢掉另一端旧值。statistics.mean 计算算术平均，stdev 使用样本标准差约定，至少需要两个数据。使用工具时应区分样本统计量与总体统计量，不能只看函数名称相近就替换。

## 随机数其实有状态
random.Random(42) 建立独立伪随机生成器。固定种子和调用顺序，在相同实现条件下有助于重现实验。它并不让随机样本“更真实”，也不保证跨所有库版本和硬件的数值逐位一致。将随机生成器作为参数传给函数，可避免模块之间偷偷共享全局随机状态。

模拟用随机性与安全用途不同。密码、令牌等应使用专门安全随机工具，不能把实验用 random 当安全来源。对科学实验，单个种子结果也可能偶然偏高或偏低，应在多个种子或重采样下评估稳定性，并保存设置。

## 时间与日志
datetime 处理日期和时间，应区分带时区与不带时区的对象；跨地区数据要明确时区。测量持续时间优先使用 time.perf_counter，而不是可能被系统校时改变的日历时间。logging 比散落的 print 更适合长期运行程序，因为可以控制级别、格式和去向；日志中不要记录口令或不必要的私人数据。

argparse 可以为脚本提供帮助信息和类型化参数，避免手工拆解命令行字符串。re 适合有规律的文本匹配，但复杂结构应优先使用专门解析器。选择标准库的原则是让问题表达更直接，而不是为了展示模块数量。

## 随机实验的两种重复
完全复现一次运行，需要相同输入、配置、生成器状态和执行流程；检验结论稳定性，则需要有计划地改变种子或重采样，观察结果分布。两者目的不同，不能只固定一个种子就宣称结论稳健。
随机抽样是否有放回、是否等概率、是否按组抽取，都影响实验含义。把一个列表打乱与从中有放回抽样不是同一件事。进行蒙特卡洛模拟前，先写清所模拟的随机机制，再选择函数。
日期数据也有类似的语义边界：一天不总是固定当地钟表上的二十四小时，跨时区和夏令时可能产生重复或缺失时刻。科学计时通常应保存明确时区或统一时间基准，并把持续时间与日历日期分开处理。
