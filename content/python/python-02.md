## 变量更像标签
把 `x = 3` 想成把“x”标签贴到整数对象 3 上，比把变量想成固定类型的盒子更适合 Python。对象有类型、值和身份；名字本身没有固定类型。随后执行 `x = "三"`，表示标签改贴到了字符串对象上，原整数并未被改造成文字。动态类型不等于没有类型，表达式仍必须满足各类型的操作规则。

常见基本类型包括整数 `int`、浮点数 `float`、布尔值 `bool`、字符串 `str` 和表示“没有结果”的 `None`。整数可表示任意精度但受可用内存限制，浮点数通常近似表示实数。布尔值用于判断，不应因为它能参与整数运算，就混淆“是否发生”和“发生次数”两个概念。

## 赋值不等于复制

<figure class="teaching-figure"><a href="assets/diagrams/python-object-alias.svg" target="_blank" rel="noopener" aria-label="打开大图：a 与 b 指向同一列表：通过任一名字修改列表内容，另一名字也能观察到变化。"><img src="assets/diagrams/python-object-alias.svg" alt="a 与 b 指向同一列表：通过任一名字修改列表内容，另一名字也能观察到变化。" loading="lazy"></a><figcaption>a 与 b 指向同一列表：通过任一名字修改列表内容，另一名字也能观察到变化。<br><small>示意普通 Python 列表的共享引用；b = a 不复制对象。重新绑定名字与修改列表内容是不同操作。 · 点按图形可放大。</small></figcaption></figure>


```python
a = [10, 20]
b = a
b.append(30)
print(a)           # [10, 20, 30]
c = a.copy()
c.append(40)
print(a == c)      # False
print(a is b)      # True
print(type(a))     # <class 'list'>
```

前两行让两个名字指向同一列表。列表可变，所以通过 b 添加元素后，从 a 也看得到改变。`copy` 创建一个新的外层列表，本例的元素是不可变整数，因此能得到预期隔离；若列表内部还有列表，浅复制仍共享内部对象。理解共享关系，可以避免数据被“隔空修改”的错觉。

## 等号的三种含义
`=` 是赋值，`==` 比较值是否相等，`is` 比较对象身份。`x is None` 是检查空结果的常见写法；比较两个数或两段文字通常使用 `==`，不要使用 `is`。某些小整数或字符串可能被解释器复用，偶然得到相同身份不能成为程序依据。数值字符串 `"12"` 与整数 `12` 也不是同一种数据，读取文本后需显式转换。

多重赋值 `x, y = y, x` 会先计算右侧，再分别绑定左侧，因此可以交换两个值。它并不等同于先执行 `x = y` 再执行 `y = x`。可读的命名应说明意义和单位，例如 `temperature_c`、`duration_s`；避免把 `list`、`str`、`sum` 等内置名称重新用作变量。

## 类型转换要有数据含义
`int("12")` 可以解释十进制整数字符串；`int("12.5")` 会失败；`int(12.9)` 向零截断，并不是四舍五入。转换不会自动证明输入合理，例如负年龄仍是合法整数。类型检查回答“是什么数据”，范围检查回答“这个数据在问题里是否允许”。两种检查需要分别考虑。

## 画出对象关系
在纸上画两个名字 a、b 和一个列表方框，用箭头表示绑定关系。执行 b=a 时只增加箭头，不增加列表；执行 b=a.copy() 时增加新列表；执行 a=[9] 时把 a 的箭头移到新对象。每次修改前先判断动的是箭头还是方框内部，再预测另一名字看到的值。
这种图也能解释函数参数：调用者把对象交给函数使用，函数内的参数名只是另一个标签。若函数向列表追加，方框内容改变；若函数把参数重新绑定，调用者的箭头仍指向原方框。不要用“参数传递会复制一切”来解释，因为它不能预测这些行为。
最后区分删除名字与删除对象。del a 移除名字绑定，不意味着其他引用看到的对象立刻消失。对象何时回收由实现和剩余引用等因素决定，正常程序不应依赖某次回收的精确时刻。

## 练习
1. 执行 `a=[1]; b=a; a=[2]` 后，b 是什么？
<details><summary>查看解析</summary>b 仍是 [1]。最后一条语句重新绑定 a，并没有修改旧列表。若执行的是 a.append(2)，则 b 会看到 [1, 2]。</details>

2. 两个分别创建的列表 `[1,2]` 应用什么判断内容相同？
<details><summary>查看解析</summary>用 ==。它按元素比较值；is 只检查是否为同一对象。两个不同列表可以相等却不相同。</details>
