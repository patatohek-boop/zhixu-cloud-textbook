## 先给数组的每个维度命名
`ndarray` 是 NumPy 的多维数组。**shape** 是各轴长度的元组；**ndim** 是轴数；**dtype** 描述元素的存储类型；**axis** 是轴编号。

### 形状之外还要约定数据含义

形状 (3,2) 只说明有三行两列，不自动说明“样本×特征”，数据含义必须另外约定。数组也可能是非连续内存视图，不能把所有数组都当连续副本。

对 A 形状 (n,p)，令 $A_{ij}$ 为第 i 个样本第 j 个特征。沿 axis=0 求平均得到 $m_j=(1/n)\sum_i A_{ij}$，因此结果有 p 项；沿 axis=1 则每个样本得到一个平均，结果有 n 项。通俗地说，归约轴是被收起来的方向。

## 广播是索引规则，不是“自动猜你的意思”
A 为 (3,2)，b 为 (2,) 时，广播相加定义 $C_{ij}=A_{ij}+b_j$，结果 (3,2)。若希望给每行加一个值 r_i，应把 r 变成 (3,1)，得到 $C_{ij}=A_{ij}+r_i$。

### 配对误差的广播陷阱

若预测为 (n,1)、真实目标为 (n,)，二者相减通常得到 (n,n)，是在每个预测与每个目标之间两两相减，而不是 n 个配对误差。

```python
import numpy as np
prediction = np.array([[1.0], [2.0], [3.0]])
target = np.array([1.0, 2.0, 4.0])
assert (prediction - target).shape == (3, 3)
residual = prediction[:, 0] - target
assert residual.shape == (3,)
assert np.allclose(residual, [0, 0, -1])
```
逐元素乘法 `*` 要求广播兼容；矩阵乘法 `@` 对内维求和。数学定义不同，形状恰好都合法也不能互换。[官方广播规则](https://numpy.org/doc/stable/user/basics.broadcasting.html) 可用于核对复杂形状。

## 数组为什么不同于列表
Python 列表能混合保存各种对象，NumPy 数组通常用统一数据类型连续组织数值，更适合大规模数值运算。安装环境准备好后，可导入 numpy；本课不需要下载外部数据。向量化把一组运算交给数组库执行，语义上仍应能解释为逐元素或矩阵运算，而不是神秘的“自动加速”。

```python
import numpy as np

readings = np.array([[20.0, 22.0], [21.0, 23.0], [19.0, 21.0]])
print(readings.shape)            # (3, 2)
print(readings.mean(axis=0))     # [20. 22.]
offsets = np.array([0.5, -0.5])
corrected = readings + offsets
print(corrected[0])             # [20.5 21.5]
mask = corrected > 22
print(corrected[mask])           # [22.5]
```

本例每行是一时刻，每列是一传感器。axis=0 沿行方向聚合，留下每列平均；axis=1 则留下每行平均。轴名称本身不等于“行”或“列”，它说明被操作或被归约的维度，最可靠的方法是结合 shape 推导输出形状。

## 广播如何工作
广播从最右侧维度比较，维度相等或其中一个为 1 时可兼容。形状 (3,2) 加形状 (2,) 时，两个偏移量分别作用于每行的两列，并非复制后才运算。形状 (3,) 不能直接与 (3,2) 相加；若想给每行一个值，应转成 (3,1)。代码能运行也未必符合语义，某些意外广播会生成更大的二维结果。

逐元素乘法使用 `*`，矩阵乘法使用 `@`，二者含义完全不同。

### 变形与转置

reshape 改变观察形状而不改变元素数量；转置改变轴顺序。进行机器学习时始终写下“样本数×特征数”，可以避免许多维度错误。

### 数组条件不是标量条件

布尔数组组合使用括号与 `&`、`|`，不能直接用标量 and、or。

## 类型、视图与副本
数组 dtype 决定存储与运算规则。整数数组赋入小数可能截断；整数类型也可能溢出，不能把 Python 整数的任意精度性质推广到 NumPy 固定宽度整数。检查 dtype 是数值结果排查的重要步骤。

基本切片常返回共享内存的视图，修改切片可能影响原数组；高级索引通常返回副本。需要独立数据时显式 copy。不要假设每种切片和变形都复制或都不复制，应根据操作契约确认。性能优化应在结果、形状和单位验证之后进行。

## 以维度表代替猜测
给每个数组写一行说明：数据含义、形状、类型和单位。经过求和、转置、拼接或矩阵乘法后，先推导输出形状再运行检查。例如样本矩阵乘权重向量，应每个样本得到一个数；若意外得到样本数乘样本数的矩阵，通常说明广播或转置错误。
创建均匀网格时，linspace 直接指定点数并可包含端点，arange 按步长生成且浮点步长可能受舍入影响。需要精确控制采样数量时，前者通常更容易解释。
数组比较会返回布尔数组，不是单个真假值。要判断是否全部满足或至少一个满足，应明确使用 all 或 any。缺失和非有限值也需专门处理：普通均值遇到非数值可能传播为非数值，不能在没有数据规则时随意换成忽略缺失的函数。

每次变形都应再次核对数据的实际含义。
