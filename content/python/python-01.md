## 先定义：程序怎样被执行
**源代码**是按语言语法写出的文本；**解释器**是读取并执行它的软件；**进程**是软件正在运行的一次实例。编辑器只负责修改文本，终端负责接收启动命令。

### 表达式与语句

**表达式**经过求值得到对象，例如 `25 + 5` 得到整数 `30`；**语句**让执行状态改变或完成操作，例如赋值和输出。`print(30)` 中函数调用也是表达式，它显示文字并返回 `None`。

本课只要求整数加法，不预设你已经懂变量。**名字绑定**指“一个名字关联到一个对象”。`minutes = 25` 先得到整数对象，再让名字 `minutes` 指向它；赋值符号不是数学等式。

## 严格规则之后的直观解释
把源代码看成菜谱，解释器看成按菜谱工作的厨师，进程是一次实际做菜。修改菜谱、保存菜谱、重新做菜是三个动作；只有重新执行，修改才进入新的计算。

## 执行跟踪：先求右边，再绑定左边
考虑依次执行 `minutes = 25`、`minutes = minutes + 5`、`print(minutes)`：

|执行位置|读取的旧值|执行后的绑定|屏幕输出|
|---|---|---|---|
|第一句|无需读取旧值|minutes → 25|无|
|第二句|25|minutes → 30|无|
|第三句|30|仍为 30|30|

这说明 `minutes = minutes + 5` 不是无法成立的数学方程，而是状态更新。若第一句缺失且进程中没有该名字，第二句求右边时就产生 `NameError`，不会自动把它当零。后面的完整脚本请从干净进程运行，交互式提示符 `>>>` 不属于代码。

## 为什么从一行输出开始
程序是一套可以重复执行的精确步骤。计算机不会补齐“差不多”“适量”之类的隐含意思，所以编程首先是把问题说清楚。可以把解释器想成翻译员：它按 Python 的语法理解指令；编辑器负责写字，终端负责启动程序，它们不是同一个东西。网站展示代码不等于在浏览器中启动完整 Python，以下代码请复制到本机运行。

## 建立最小可用环境
安装 Python 3 的受支持版本后，在系统终端输入 `python --version` 检查解释器；Windows 也可能使用 `py --version`。不同电脑启动命令可能不同，应以实际输出为准。输入 `python` 进入交互式环境后会看到 `>>>`，它是提示符，不是要复制的代码。交互式环境适合试算；脚本适合保存完整工作。新建 UTF-8 编码的 `hello.py`，写入下面三行，然后在文件所在目录执行 `python hello.py`。

```python
name = "学习者"
minutes = 25
print(f"{name}，今天专注学习 {minutes} 分钟。")
```

第一行把名字绑定到一段文字，第二行保存一个整数，第三行将二者组合后显示。输出应为“学习者，今天专注学习 25 分钟。”。把 25 改为 40，重新保存并运行，观察输出变化。这种“预测—实验—解释”的循环，比一次性复制很多代码更能建立理解。

## 输入、处理、输出
把任何小程序画成三格：输入是什么，按照什么规则处理，输出是什么。本例输入是写死在文件里的名字和时长，处理是格式化，输出是终端文字。

### 加入键盘输入

下一步可以将第一行改成 `name = input("你的名字：")`。注意 `input` 返回字符串，即使输入 25，也暂时是文字而不是数值。读取用户输入会等待键盘操作，自动运行时应避免无提示地等待。

脚本从上往下执行，所以把输出放在变量定义之前会报错。交互式环境会保留之前的变量，容易让缺少定义的片段“碰巧能运行”；验证脚本时应从干净进程开始。Notebook 也有类似问题：单元格显示顺序不一定是实际执行顺序。可复现的程序应当从第一步顺序执行即可得到结果。

## 常见问题与排查
若提示找不到命令，检查安装和解释器路径；若提示找不到文件，检查终端当前目录和文件名；若出现语法错误，检查英文引号、括号和缩进。不要把错误都归因于“电脑坏了”。

### 利用错误信息定位

完整错误信息中的文件、行号、异常名称是定位线索。先保存文件再运行，并确认文件没有被编辑器保存成 `hello.py.txt`。

## 小实验：程序执行与保存是两回事
将名字改为自己的昵称后，先故意不保存就运行一次，再保存后运行一次。前一次可能仍显示旧结果，因为解释器读取的是磁盘文件，不是编辑器尚未保存的内容。再把输出语句复制到文件末尾，确认它会执行两次。通过这些小变化，可以把“屏幕显示”“内存状态”“文件内容”三者分开理解。

## 从交互式返回终端再运行脚本

看到 `>>>` 时，输入 `exit()` 并回车，回到系统终端；`python hello.py` 是终端命令，不能写在 `>>>` 后。用编辑器把脚本保存到自己能找到的文件夹，再让终端进入同一文件夹。

例如 Windows 把文件保存在用户目录的 `python-course` 文件夹时，PowerShell 中先输入 `cd "$HOME\python-course"`；macOS/Linux 的对应例子是 `cd ~/python-course`。这些路径只是示例，应与实际保存位置相同。随后运行 `python hello.py`；若安装提供的是 `py` 或 `python3`，全文命令相应使用同一个已确认的解释器入口。

先确保本节三行脚本独立运行成功，再进入后续章节。第三方库的准备集中在[模块与虚拟环境](#/course/python/python-11)，前面的基础课只使用解释器自带功能。
