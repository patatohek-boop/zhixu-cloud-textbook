## 训练是反复修正参数
对可微目标 J，梯度下降使用
$$\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t),$$
其中 $\eta>0$ 是学习率。想象在山坡上看局部坡度并迈一小步，负梯度指出局部下降方向，学习率决定迈多远。步子过小训练缓慢，过大可能越过低谷并发散；没有一个对所有问题都最优的固定学习率。

```python
w = 0.0
learning_rate = 0.1
for step in range(20):
    loss = (w - 3.0) ** 2
    gradient = 2.0 * (w - 3.0)
    w -= learning_rate * gradient
print(round(w, 4))  # 2.9654
```

这里最优值为 w=3。第一步梯度 -6，更新为 0.6；第二步梯度 -4.8，更新为 1.08。误差满足 $w_{t+1}-3=(1-2\eta)(w_t-3)$，所以这个二次问题在 $0<\eta<1$ 时收敛。该区间来自本例曲率，不能直接套到其他损失。

## 批量、随机与小批量
批量梯度每步使用全部训练样本，方向较稳定但单步成本大。随机梯度每步使用一个样本，小批量梯度使用部分样本，更新含噪声但可更快推进。一个 epoch 表示大致遍历一遍训练数据，step 表示一次参数更新，二者不是同义词。

平方损失 $J=\|Xw-y\|^2/(2n)$ 的梯度为 $X^\top(Xw-y)/n$。先检查维度：残差为 n 维，乘 X 转置后为 p 维，与 w 一致。特征尺度差异大时，等高线可能狭长，梯度步骤左右摇摆；标准化能改善许多问题的优化条件，但应仅用训练数据拟合。

## 梯度如何验证
可用中心差分近似某一偏导：
$$\frac{\partial J}{\partial\theta_j}\approx\frac{J(\theta+\epsilon e_j)-J(\theta-\epsilon e_j)}{2\epsilon}.$$
将数值近似与解析或自动微分结果比较，可发现链式法则或维度错误。epsilon 太大会有截断误差，太小会受舍入影响，应在小规模、双精度测试中选择合理尺度。

训练损失下降不等于泛化变好，应同时看验证指标。梯度接近零可能是最小点、鞍点或平坦区；非凸优化不能仅凭停止就宣称全局最优。停止规则可结合最大迭代、目标变化、梯度范数和验证表现，避免无限运行。

## 观察轨迹而不只看终点
记录每一步参数、训练目标和梯度范数，可以区分缓慢收敛、震荡与发散。若损失突然变成非数值，应先检查输入是否有限、学习率是否过大、指数对数是否稳定，再考虑更复杂的优化器。
对于多参数二次目标，不同方向曲率不同，稳定步长受到最大曲率限制。某个方向更新合适，另一方向仍可能跨过谷底，这也是尺度调整与预条件方法的动机。把参数单位换算后，原学习率未必仍合适。
小批量训练中的损失会抖动，不能要求每一步严格下降；应看合理窗口内的趋势，并与独立验证结果配合。批次顺序和随机种子影响轨迹，比较方案时应保留可复现设置。
优化终止后还要检查约束和物理含义。一个数值上收敛的参数若产生负的绝对温度或违反守恒，并不因损失较小就成为可接受模型；必要时应在模型结构或目标中加入相应约束。

数值收敛与实际有效需要分别验证。
