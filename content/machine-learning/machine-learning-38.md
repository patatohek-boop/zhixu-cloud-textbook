## 前向模型已经知道，反问题还难在哪里

**前向问题** 给定参数预测温度；**反问题** 根据温度观测推断参数。沿用[问题契约](#/course/machine-learning/machine-learning-36)，设

$$f(t;h)=T_a+\Delta_0 e^{-\beta t},\quad
\Delta_0=T_0-T_a,\quad \beta=\frac{hA}{mc}.$$

本节首先假设 $m,c,A,T_0,T_a$ 已知且固定，$m,c,A>0$，$\Delta_0\ne0$，唯一未知量为 $h>0$；时间零点准确，传感器滞后已校准或可忽略。后面专门撤销“比热已知”的假设，看看答案如何改变。

对给定时刻 $t_i$，采用观测模型 $y_i=f(t_i;h)+\varepsilon_i$。数据、物理模型和噪声模型共同决定反演结果，不能只交付一份最小化代码。

## 一条理想读数能否唯一确定 h

### 无噪声时，先检查映射是否一一对应

若 $t>0$ 且冷却读数满足 $0<(y-T_a)/\Delta_0<1$，取对数得

$$h=-\frac{mc}{At}\ln\frac{y-T_a}{\Delta_0}.$$

因此在上述已知量和正参数条件下，一个理想读数已经唯一确定 $h$。初始时刻 $t=0$ 的温度与 $h$ 无关，不能反演。$\Delta_0=0$ 时物体与环境始终同温，任意 $h$ 都给相同曲线。

这里的“唯一”是模型内的结论。带噪读数可能越过环境温度，使对数无定义；即使对数存在，它也会改变误差分布。实际拟合通常直接在温度尺度比较模型与数据，而不是无条件地把取对数当作线性回归捷径。

### 结构可辨识与实际可辨识

**结构可辨识性** 问：在理想观测条件下，不同参数能否产生完全相同的观测分布或轨迹？必须说明已知量、观测位置和采样方案。

**实际可辨识性** 问：在当前噪声、时间范围和样本量下，不同参数能否可靠地区分？理想上唯一的参数，在数据不敏感的区间也可能估得很差。曲线上两条线只差 0.01 K，而测量波动为 1 K，便是后者的典型图像。

## 同时估 h 和 c：为什么谷底变成一条长带

### 用不变性直接证明混淆

若 $c$ 也未知，指数只含比值 $h/c$。对任意 $\lambda>0$，

$$f(t;\lambda h,\lambda c)=f(t;h,c)\qquad\text{对所有 }t\ge0.$$

例如 $(h,c)=(18,900)$ 与 $(36,1800)$ 的整条预测完全相同。即使无限密集、完全无噪声地记录这一条冷却曲线，也不能区分它们。这不是优化器不够强，而是实验没有提供所需信息。

若噪声分布也不额外依赖 $h,c$，两组参数的似然同样相同。再采更多相同类型的冷却数据只会更清楚地确定比值，不会自动把分子、分母拆开；可另测比热、测已知加热功率下的热容响应，或加入有独立物理依据的先验。

### 灵敏度矩阵把混淆变成线性代数

**灵敏度** 是预测对参数的局部导数；对 $n$ 个观测、$p$ 个参数，令 $J_{ij}=\partial f(t_i;\theta)/\partial\theta_j$。小扰动满足

$$f(\theta+\delta\theta)-f(\theta)\approx J\delta\theta.$$

本例中

$$\frac{\partial f}{\partial h}=-\frac{At}{mc}\Delta_0e^{-\beta t},\qquad
\frac{\partial f}{\partial c}=\frac{hAt}{mc^2}\Delta_0e^{-\beta t}
=-\frac hc\frac{\partial f}{\partial h}.$$

两列成比例，秩最多为一；方向 $(h,c)^\top$ 满足 $J(h,c)^\top=0$，对应刚才的同比例缩放。画二维损失面时，低损失区域沿 $h/c$ 不变的方向延伸。狭窄的横向宽度不意味着沿长带的两个参数也精确。

参数单位不同会影响列的数值大小。比较敏感程度前可选无量纲参数 $\log(h/h_{\rm ref})$ 与 $\log(c/c_{\rm ref})$；缩放改善数值条件，却不会改变这里的列相关和信息缺失。

## 从高斯似然推导信息矩阵

### 得分函数：数据如何推动参数

设 $\varepsilon\sim N(0,\Sigma)$，$\Sigma$ 已知、正定且不随参数改变。记 $r=y-f(\theta)$。忽略与参数无关的常数，

$$\ell(\theta)=-\frac12r^\top\Sigma^{-1}r,\qquad
s(\theta)=\nabla_\theta\ell=J^\top\Sigma^{-1}r.$$

$s$ 称为得分向量。**Fisher 信息矩阵** 定义为 $\mathcal I(\theta)=E_\theta[ss^\top]$。由于 $E[rr^\top]=\Sigma$，

$$\mathcal I=J^\top\Sigma^{-1}\Sigma\Sigma^{-1}J
=J^\top\Sigma^{-1}J.$$

独立且同方差 $\sigma^2$ 时，标量 $h$ 的信息为 $\mathcal I_h=\sum_i (\partial f_i/\partial h)^2/\sigma^2$。同样大的曲线变化，在更小噪声下更容易辨认。若噪声协方差也含未知参数，上式不再是完整信息公式。

### 信息倒数是什么，不是什么

在线性化合理、参数可辨识、模型正确并满足适当大样本正则条件时，MLE 的协方差常用 $\mathcal I(\hat\theta)^{-1}$ 近似。它是局部精度尺度，不是任意有限样本的精确后验，也不保证无偏。

标量情形还能给出无偏估计的下界。假设分布支撑不随参数变化，允许对积分求导，$E_h[\hat h]=h$，且得分与估计量有有限二阶矩。对等式求导并用 $E_h[s]=0$，得到

$$1=E_h[(\hat h-h)s].$$

由 Cauchy–Schwarz 不等式，$1\le\operatorname{Var}_h(\hat h)\mathcal I_h$，所以 $\operatorname{Var}_h(\hat h)\ge1/\mathcal I_h$。达到下界需要额外条件，不能看见这个公式就给任意神经网络估计器套上“精度保证”。可对照 [Ly 等人的 Fisher 信息教程第 1.2 节及附录 B](https://arxiv.org/pdf/1705.01064)。

## 完整手算：一个读数究竟有多少信息

沿用合成参数 $m=0.2$、$c=900$、$A=0.01$、$h=18$，单位与[第 36 节](#/course/machine-learning/machine-learning-36)相同。$\beta=0.001\,\mathrm{s^{-1}}$，$\Delta_0=60\,\mathrm K$。

**第一步：由理想温度恢复参数。** 在 $t=1000\,\mathrm s$，设合成读数精确为 $20+60/e$。代入逆公式：

$$h=-\frac{180}{0.01\times1000}\ln(e^{-1})=18\,\mathrm{W/(m^2\cdot K)}.$$

**第二步：计算敏感程度。** 此时

$$\frac{\partial f}{\partial h}=-\frac{1000}{18000}\frac{60}{e}
=-\frac{10}{3e}\approx-1.22626.$$

导数单位为“开尔文除以换热系数单位”。在足够小的局部扰动下，$h$ 增加 0.1 会使预测温度约下降 0.1226 K；这个线性估计不能任意外推到大幅参数变化。

**第三步：引入假想重复实验的噪声。** 若该时刻独立观测标准差为 $1\,\mathrm K$，信息为 $\mathcal I_h\approx1.50373$，其倒数平方根约为 $0.81548\,\mathrm{W/(m^2\cdot K)}$。这表示该模型的局部精度尺度，不表示一次读数必定在此范围内。

### 为什么 t=τ 是这个特定问题的最佳单次时刻

在仅估 $h$、固定同方差噪声、每次读数成本相同且允许任意 $t\ge0$ 时，单点信息与 $g(t)=t^2e^{-2\beta t}$ 成正比。求导：

$$g'(t)=2te^{-2\beta t}(1-\beta t).$$

它在 $0<t<1/\beta$ 为正，此后为负，故全局最大点为 $t=\tau$。很早时参数尚未使曲线分开，很晚时温差已经衰减到噪声附近。若还要估初温、存在传感器滞后、噪声随时间改变或实验成本取决于等待时长，最优设计会改变。

## 可运行复算与图像阅读

以下 Python 3 程序只需标准库。中心差分从两次温度计算估导数，与解析灵敏度独立比较；它是本例的数值检查，不代替前面的推导。

```python
import math

m, c, area = 0.2, 900.0, 0.01
h, ambient, initial = 18.0, 20.0, 80.0

def temperature(t, coefficient):
    return ambient + (initial - ambient) * math.exp(
        -coefficient * area * t / (m * c)
    )

t = 1000.0
step = 1e-4
numeric = (temperature(t, h + step) - temperature(t, h - step)) / (2 * step)
analytic = -area * t / (m * c) * (temperature(t, h) - ambient)
assert math.isclose(numeric, analytic, rel_tol=1e-8)
observed = temperature(t, h)  # 合成无噪声观测
estimate = -m * c / (area * t) * math.log((observed - ambient) / (initial - ambient))
print(round(estimate, 6), round(analytic, 6))
```

输出约为 `18.0 -1.226265`。阅读本节交互实验时，先固定观测再改变候选 $h$：观察早、中、晚三段曲线的分离，而不只盯住一个损失数。然后思考：若允许 $c$ 同比例改变，这种分离为什么消失？不要把每次拖动生成的一条新曲线当作新取得的真实实验数据。

## 练习与解析

### 练习一：更多相同实验能分开 h 与 c 吗

在已知初温和环境温度条件下，再做十次相同几何的无内热源冷却，可以解除 $h/c$ 混淆吗？

若这些实验仍只通过同一比值决定轨迹，不能。独立重复可以缩小比值的估计误差，却保留同比例缩放不变性。需要对 $c$ 或 $h$ 提供独立约束；单纯给优化器设置某个初值不是新信息。

### 练习二：初温也未知时为什么不能只在 τ 重复测

同时估 $\Delta_0$ 和 $h$，所有读数取相同的正时刻 $t_*$。两列灵敏度分别是什么？

<details><summary>查看解析</summary>

各行均为 $\big(e^{-\beta t_*},-At_*\Delta_0e^{-\beta t_*}/(mc)\big)$，所以矩阵秩最多为一。重复再多也只确定该时刻的平均温差。选择不同时间以产生不同列比例，才可能局部区分两个参数；还需检查噪声和信号强度。

</details>

### 练习三：传感器噪声减半与重复四次

在标量可辨识模型中，比较标准差减半与由单次改为四次独立同条件读数对信息的影响。

<details><summary>查看解析</summary>

两者都使信息变为原来的四倍、局部标准差尺度减半。这个等价依赖独立同方差、无共同偏差等假设；若四次只是高度相关的连续读数，应使用完整 $\Sigma$，不能直接乘四。

</details>
