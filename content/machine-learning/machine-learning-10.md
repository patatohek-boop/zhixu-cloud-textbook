## 对数优势与逻辑回归模型
标签 y∈{0,1}，先取概率 0<p<1，使下面的有限对数有定义；p=0 或 1 只能作为极限讨论。**优势**为 p/(1−p)，**对数优势（logit）** 为 $\log[p/(1-p)]$，这里 log 是自然对数。

### 从对数优势到概率

逻辑回归假设 logit 等于线性分数 z=wᵀx+b，解方程得 $p=\sigma(z)=1/(1+e^{-z})$。这是概率模型假设，并非任何二分类数据必然满足的规律。

给定特征，伯努利标签的概率质量为 $p^y(1-p)^{1-y}$。样本条件独立时似然相乘，负对数为逐样本交叉熵之和。换言之，训练希望把真实发生的类别分配到高概率，而不是只关心是否跨过某个阈值。

## 交叉熵的梯度与凸性
$\sigma'(z)=e^{-z}/(1+e^{-z})^2=p(1-p)$。对
$\ell=-y\log p-(1-y)\log(1-p)$，
$$\frac{d\ell}{dp}=-\frac yp+\frac{1-y}{1-p}=\frac{p-y}{p(1-p)}.$$


### 第二步：沿计算链求参数梯度

链式法则乘上 dp/dz 得 $d\ell/dz=p-y$，再乘 x 得对 w 的梯度 $(p-y)x$。

### 第三步：检查凸性

二阶导 $d^2\ell/dz^2=p(1-p)\ge0$；整个线性模型 Hessian 为 $X^\top DX$，D 的对角为各 p_i(1−p_i)，所以 $v^\top X^\top DXv=\sum_iD_{ii}(x_i^\top v)^2\ge0$，目标凸。

凸不保证有限最小点存在：可分数据能把正确类别分数推向无穷，让损失趋零却不在有限参数取到。正则化与数据条件必须另外考虑。

## Softmax 的归一化与数值稳定性
互斥 K 类分数 z₁,…,z_K，$p_k=e^{z_k}/\sum_je^{z_j}$。各项非负且和为一。

### 减最大值为何保持概率不变

所有分数减同一 c 后，分子分母都有 e⁻ᶜ，约掉后概率不变，因此可取 c=max z 防指数溢出。

### softmax 交叉熵的梯度

真实类为 r，损失 $\ell=-z_r+\log\sum_je^{z_j}$，直接求偏导得
$$\frac{\partial\ell}{\partial z_k}=p_k-\mathbf1\{k=r\},$$
其中指示函数在条件成立时为一，否则为零。多标签任务各标签可同时成立，不满足互斥类别契约，不能强行使用这个和为一的输出。

## 概率输出与分类决策
二分类逻辑回归先计算分数 $z=w^\top x+b$，再通过 sigmoid：
$$p(y=1|x)=\sigma(z)=\frac1{1+e^{-z}}.$$
输出介于零与一之间。模型假设对数优势 $\log[p/(1-p)]$ 是特征的线性组合，因此在原特征空间中，固定概率阈值通常对应线性决策边界。

概率与决策是两步。默认阈值 0.5 只是常见约定，漏报与误报成本不同时可在验证集选择其他阈值。把概率 0.51 和 0.99 都判为正类，会丢失置信程度差异；部署时常需要保留概率或分数供后续规则使用。

## 例题
若 $z=\log3$，则 $e^{-z}=1/3$，概率为 3/4。真实标签为 1 时，二元交叉熵为 $-\log0.75\approx0.288$；若模型给出 0.01，则损失约 4.605。自信而错误的预测被强烈惩罚，这符合概率建模的目的。

二元交叉熵为
$$L=-y\log p-(1-y)\log(1-p).$$
它来自伯努利似然的负对数。对线性分数 z 求导可简化为 p-y，这使梯度形式直观：预测概率高于实际标签时向下调整，低于时向上调整。实现时应使用数值稳定的损失函数，不直接对接近零的概率取对数。

## 多分类与多标签不同
互斥 K 类可使用 softmax：
$$p_k=\frac{e^{z_k}}{\sum_j e^{z_j}}.$$
各类概率之和为一，交叉熵取真实类别概率的负对数。计算时先从所有分数减去最大值，不改变比例，却能减少指数溢出。一个样本可同时拥有多个标签时，不应强迫所有标签概率加和为一，常用独立 sigmoid 与相应损失。

一对其余策略分别训练每类与其他类的分类器，也是多分类处理方式；概率解释与校准需要检查。线性可分数据下，无正则逻辑回归参数可能持续增大而没有有限最大似然解，因此正则化不仅影响泛化，也可改善估计行为。

## 系数与适用边界
某特征增加一单位时，其他特征固定，对数优势增加对应系数，优势乘以该系数的指数。它不是概率固定增加某个数，概率变化还取决于起点。尺度、相关性、交互和遗漏变量都影响解释。逻辑回归是强有力的基线，但不意味着所有概率都自动校准良好。

## 从优势比回到概率
若原概率为二分之一，优势为一，某特征变化使优势乘以二，则新概率为三分之二；若原概率为十分之一，优势为九分之一，乘二后概率为十一分之二。相同优势倍数并不对应相同概率增量。
因此解释系数时应说明其他特征固定，并结合代表性输入展示预测概率变化。高相关特征使“只改变一列、其他不变”的场景可能缺乏现实支持，解释应避开没有数据的组合。
分类边界由阈值决定，但训练损失通常使用完整概率。若只优化硬分类正确与否，目标可能不连续且忽略置信度；交叉熵提供平滑的概率学习目标，之后再根据成本选择决策规则。

## 从概率到梯度：完成一次可核查的更新

取四个一维训练点 x=[−2,−1,1,2]、y=[0,0,1,1]，初始 w=b=0。采用**平均**交叉熵，因此梯度必须除以 n=4。

### 第一步：计算四个概率和误差信号

四个分数都为零，所以概率均为 1/2，p−y 依次为 [1/2,1/2,−1/2,−1/2]。截距梯度是它们的平均，等于零。

### 第二步：乘特征，再取平均

权重梯度为 $[(-2)(1/2)+(-1)(1/2)+1(-1/2)+2(-1/2)]/4=-3/4$。学习率取 0.2，一步后 w=0.15、b=0。四个新分数为 [−0.30,−0.15,0.15,0.30]，正确类别的概率均比更新前增加。

### 第三步：运行并核对目标下降

```python
import math

x = [-2.0, -1.0, 1.0, 2.0]
y = [0, 0, 1, 1]
w, b = 0.0, 0.0

def mean_loss(weight, bias):
    terms = []
    for value, label in zip(x, y):
        z = weight * value + bias
        terms.append(max(z, 0.0) - label * z
                     + math.log1p(math.exp(-abs(z))))
    return sum(terms) / len(terms)

probabilities = [1.0 / (1.0 + math.exp(-(w * value + b))) for value in x]
grad_w = sum((p - label) * value
             for p, label, value in zip(probabilities, y, x)) / len(x)
grad_b = sum(p - label for p, label in zip(probabilities, y)) / len(x)
old_loss = mean_loss(w, b)
w, b = w - 0.2 * grad_w, b - 0.2 * grad_b
assert math.isclose(w, 0.15) and b == 0.0
assert mean_loss(w, b) < old_loss
print(round(old_loss, 4), round(mean_loss(w, b), 4))  # 0.6931 0.5877
```

损失写成 `max(z,0) - y*z + log1p(exp(-abs(z)))`，与二元交叉熵相同，但不需要先算接近零的概率再取对数。四点示例只检验本次训练更新；它们恰好线性可分，不能据此认为无正则化的权重最终存在有限最优值，也不能把训练分类全对当作未来性能。
