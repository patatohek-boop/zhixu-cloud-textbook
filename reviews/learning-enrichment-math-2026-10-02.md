## 加速学习路径：按能力过关，不按天数承诺

### 第一段：先能把问题写对

必学：`calculus-01` 和 `linear-algebra-01`。两条线可并行。完成标准是能写清输入、输出、每个分量及单位，并把简单向量组合拆成逐行等式。

按需补：分数运算、一元一次方程、指数运算、区间交集。初等代数没有独立新课号，使用 `calculus-01` 的定义域例题和 `linear-algebra-01` 的逐分量例题定位缺口。不要用“看过”替代亲手算一次。

### 第二段：掌握变化与方程两套基本工具

微积分顺序：`calculus-01 → calculus-02 → calculus-03 → calculus-04`。其中 02、04 是必要补课，未在本轮重写。先理解极限，再由差商求导，最后学习乘积、商和链式求导。

线性代数顺序：`linear-algebra-01 → linear-algebra-02 → linear-algebra-03`。完成标准是能识别无解、唯一解与自由参数，并解释矩阵每一行/列以及乘法接口。

### 第三段：从工具到热/流体/数据入口

必学：`calculus-07`、`calculus-15` 和 `linear-algebra-10`。07 解决速率累积为总量；15 解决位置、时间等输入共同变化；10 解决观测不能精确拟合时的最近预测。

投影前补 `linear-algebra-05` 与 `linear-algebra-06`，读懂子空间、张成和基。07 的第一遍计算与建模不要求先精通优化/牛顿法；完整积分证明还需回读 `calculus-05` 的中值定理及 `calculus-25` 的完备性与一致连续性。15 的混合偏导交换证明使用 07，完整空间几何训练可补 `calculus-14`。

### 第四段：按用途分流，避免所有高级主题同时压上来

- 热/流体方向：从 `calculus-15 → calculus-16` 学梯度与方向导数；在 07 后学习 `calculus-08` 的基本积分技巧，再进入 `calculus-24` 的基础微分方程。空间累计问题再接 `calculus-18`，体积积分、散度定理按 `calculus-19 → calculus-22` 展开。这些是后续学习节点，本轮没有为它们新增完整分层内容
- 机器学习方向：由 `linear-algebra-10 → linear-algebra-11` 进入最小二乘；由 `calculus-15 → calculus-16` 理解梯度。掌握向量空间与矩阵后再读 `linear-algebra-13` 的特征方向，按具体任务继续到 `linear-algebra-15`、`linear-algebra-18` 与 `linear-algebra-22`，不要把 PCA/SVD 当作还不会矩阵乘法时的第一课

### 可后置的内容及边界

首轮应用练习可后置 `calculus-25` 的完整实数构造/紧致证明、`calculus-26` 的一致收敛、`calculus-27` 的隐函数理论、`calculus-28` 的洛必达证明、`calculus-30` 的辛普森误差证明和 `calculus-31` 的完整换元误差证明。若当前题目依赖对应定理的合法性，必须回读，后置不是删除条件。

线性代数可按需求后置 `linear-algebra-17` 的复内积/Fourier、`linear-algebra-23` 的 Jordan 链和 `linear-algebra-24` 的矩阵指数/Markov 收敛证明。数值算法应用前，`linear-algebra-20` 的条件数与数值可靠性值得补读；它不属于“可以永远忽略”的内容。

## 关键依赖边为什么存在

- `calculus-01 → calculus-02`：极限先要有函数、允许输入与邻近点的概念
- `calculus-02 → calculus-03`：导数是非零差商的极限，不能把 0/0 当作代入
- `calculus-03 → calculus-04`：快捷求导规则要建立在变化率定义上
- `calculus-02、03、04 → calculus-07`：用极限理解累计、用导数识别原函数、用求导规则核对积分结果
- `calculus-05、25 → calculus-07` 的深入层：中值定理用于原函数只差常数，完备性/一致连续性用于可积性论证
- `linear-algebra-01 → linear-algebra-02`：行操作需要先明确每行是一个同时满足的约束
- `linear-algebra-01、02 → linear-algebra-03`：分量与方程给矩阵含义，消元给逆与求解的背景
- `linear-algebra-03 → linear-algebra-05 → linear-algebra-06`：从具体线性规则抽象出封闭的空间，再找独立坐标与维数
- `linear-algebra-03、05、06 → linear-algebra-10`：投影需要矩阵/点积计算，并知道允许预测的子空间及其方向
- `calculus-03、04、linear-algebra-01 → calculus-15`：多个分量各用单变量变化率，链式法则把全部依赖路径接起来
- `calculus-15 → calculus-16`：先明白偏导与统一线性近似，梯度才不是一串没有含义的符号
- `linear-algebra-10 → linear-algebra-11`：最小二乘把投到一个方向扩展为投到设计矩阵的列空间
- `calculus-07 → calculus-08 → calculus-24`：累积/原函数和基本积分方法支撑可分离等基础微分方程求解
